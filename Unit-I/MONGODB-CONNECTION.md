
# MongoDB Connection Approach

## 1. Database
We use MongoDB as our NoSQL database.

## 2. Cloud Database
MongoDB Atlas is used to host the database in the cloud.

## 3. Node.js Integration
The MongoDB Node.js Driver is used to connect the Node.js backend with MongoDB.

## 4. Connection URI
The application uses a MongoDB connection URI to establish a database connection.

## 5. Environment Variables
Database credentials are stored securely using environment variables.

## 6. Data Storage
Student and assignment information will be stored as documents inside MongoDB collections.

## 7. Security
Database passwords and connection credentials must not be committed to GitHub.
